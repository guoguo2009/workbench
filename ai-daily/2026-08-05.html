Google DeepMind 发布 Gemini Robotics 2：机器人"大脑"实现全身统一控制

8月2日 · 来源：Google DeepMind / 36氪 / 澎湃新闻

Google DeepMind 于8月2日发布 Gemini Robotics 2 系列模型，这是其视觉-语言-动作（VLA）模型的重大升级。相比上一代仅控制上半身完成桌面任务，新模型实现了 22个自由度全身统一控制，让机器人从"脚趾到指尖"协调运动，消除了传统"停止-思考-再行动"的高延迟模式。

此次发布包含三款模型：

• Gemini Robotics 2（VLA模型）：将视觉与语言直接转化为全身动作，支持行走、蹲下、弯腰同时操控物体
• Gemini Robotics ER 2（推理系统）：可规划包含数百个步骤的长程任务，支持多机器人协作与自我纠错
• Gemini Robotics On-Device 2（端侧模型）：本地运行，仅需 不到200个示例数据、数小时即可适配新机器人本体

在演示中，搭载该模型的 Apptronik Apollo 2 人形机器人完成了穿越房间拾取物品的全流程操作，拧灯泡测试成功率达 92%。同步推出的 ASIMOV-Agentic 安全基准，让机器人能主动拒绝不安全操作并在人员靠近时自动停机。

值得关注 Gemini Robotics 2 的核心突破在于将"大脑"与"小脑"统一到单一模型——机器人不再需要分阶段控制运动和操作，而是像人类一样边走边做。On-Device 2 版本仅需200个样本即可跨本体迁移，直接抹平了本体厂商在数据集和仿真环境搭建上的巨大成本，可能推动行业从"各自为战的算法探索"全面转向工程化落地。
AI Coding 范式演进

从 Loop 到 Graph：AI Coding 范式六周内再次迭代，Y Combinator 开源多 Agent 框架

7月底-8月初 · 来源：钛媒体 / NeuralCoreTech

仅仅在 Loop Engineering 概念走红六周后，AI Coding 领域已开始讨论 Graph Engineering。起因是当 Coding Agent 从单次回答走向连续执行、从单个 Agent 走向多 Agent 协作时，工程师面对的问题从"怎样让它继续做"扩展到了"这些工作该怎样连接"。

Loop 解决的是一个 Agent 的循环迭代（读报错→修代码→重运行），但复杂任务需要分工、并行、回退和交接——研究 Agent、编码 Agent、测试 Agent 谁先开始？测试失败回到哪里？Graph Engineering 本质是一个任务编排系统，管理多个工作单元之间的连接、共享状态与选择路径。

与此同时，Y Combinator 于7月31日开源了 QM 多 Agent 框架（MIT 许可证），这是 YC 内部用于会计、法务、活动和工程工作的"多人"编排工具。QM 采用模型无关核心，可在 Claude Code、Codex、OpenCode 等不同 Agent 之上运行，代表了"harness 层"（编排层）正成为比模型本身更重要的差异化方向。

值得关注 两件事指向同一趋势：AI Coding 的竞争焦点正从"模型能力"转向"编排能力"。Graph Engineering 回应了多 Agent 协作的真实工程需求，而 YC 开源 QM 则证明编排层可以独立于模型存在。BenchLM 8月4日更新的 SWE-bench Verified 排行榜显示，前三名（Claude Opus 5: 96%、Claude Mythos 5: 95.5%、Claude Fable 5: 95%）差距仅 1%，模型层趋于同质化，编排层的差异化将决定下一个阶段的胜负。

面壁智能开源 ForgeStencil：AI 一周自动重构优化百款工业软件，全程零人工干预

8月4日 · 来源：新智元

面壁智能联合 OpenBMB 开源社区于8月4日发布并开源了全球首个 Stencil 优化"自动研究+自动部署"大闭环 AI 系统——ForgeStencil。该系统仅用 1周时间就自动完成了 100+ 真实工业和科学计算软件的重构优化，全程 0人类专家介入。

Stencil（模板计算）是工业软件（如 CAE 仿真、流体力学计算、电磁 EDA）底层最基础也最耗算力的计算模式。过去优化这类代码需要 HPC 专家逐个手工调试，每人每年优化的应用通常不超过 20 个。ForgeStencil 实现了从自动分析应用、定位热点函数、锻造 Kernel，到算子替换、正确性验证与集成回原应用的全自动闭环。

这是面壁智能继5月发布全球首个完全由 AI 编写的大模型预训练框架 ForgeTrain（训练速度比英伟达 Megatron 快 10%）后，基于 Forge Engineering（锻造工程） 范式的又一成果，标志着 AI Coding 正从应用层向底层系统软件渗透。

值得关注 这是 AI Coding 从"写业务代码"向"优化底层高性能计算代码"跨越的标志性事件。工业软件性能优化长期依赖极少数 HPC 专家，ForgeStencil 证明了 AI 可以在需要深度领域知识的系统级编程任务中实现全自动闭环。如果这一范式可推广，中国工业软件"算法功能强但跑得慢"的核心瓶颈有望被系统性突破，这对制造业自主可控具有战略意义。
